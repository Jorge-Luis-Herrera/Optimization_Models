# Introduction to the optimization

## The General Optimization Problem

    A problem of optimization is minimize (or maximize) a objetive function subject to certain restriccions .

    - min f(x) s.a. x ∈ ℳ

    Find x* ∈ ℳ such that >

    - f(x*) ≤ f(x), ∀ x ∈ ℳ

#### Main Elements of the model
* x : Decision var.
* ℳ : Set of feasible solutions.
* f(x) : Objetive function.
* x* : Optimal solution or min global value of f(x) on ℳ.
* feasible point : A point x ∈ ℳ.
* Infeasible : Un punto x ∉ ℳ.

### ***Non Lineal Programming***
    ***min f(x)
    s.a. hi(x) = 0, i = 1,...,m
    gj(x) ≤ 0, j = 1,...,s***

Where f, hi, gj : ℝn → ℝ.


### ***Lineal Programming***

    min cTx
    s.a. Ax = b
    Cx ≤ d

With c ∈ ℝn, A ∈ ℝm×n, b ∈ ℝm, C ∈ ℝs×n, d ∈ ℝs.

### Classification of Non Lineal Problems

#### according the restrictions
- Unrestricted: m = s = 0 ⇒ min f(x), x ∈ ℝn.
- with equality constraints : s = 0 ⇒ min f(x) s.a. hi(x) = 0 .
- with inequality constraints : m = 0 ⇒ min f(x) s.a. gj(x) ≤ 0.

#### According to the functions structure 
- Convex Problem : f y gjare convex , hi are compatible.
- quadratic problem : f is a quadratic function ,h and g are compatible .
- Lineal Problem : f,h and g are compatible lineal functions 

### Convexity propieties 
A function f: ℝn → ℝ is convex if  ∀ x1, x2 y α ∈ [0,1]:
> f(α x1 + (1-α) x2) ≤ α f(x1) + (1-α) f(x2)

Proposition : if f ∈ C^2,if is convex ⇔ ∇^2 f(x)  is semidefinite positive ∀ x ∈ ℝn.
